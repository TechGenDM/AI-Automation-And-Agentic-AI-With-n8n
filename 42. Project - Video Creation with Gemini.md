# Module 42: Project - Video Creation with Gemini

## Overview

This module explains how to build a UGC-style video creation workflow using n8n, Telegram input, Nano Banana image editing, and Google Gemini / v3 video generation APIs. The project demonstrates a feedback loop for image creation, conversion to hosted URLs, and generating short video outputs from AI instructions.

---

## Project objective

The goal is to create a complete media automation pipeline that:

- receives image input from Telegram
- sends the image to Nano Banana for editing
- captures user feedback and iterates on the image
- converts the final image into a shareable URL
- generates a short mobile-friendly video using Gemini v3
- uses an AI director-style agent to craft prompts and video instructions

---

## High-level workflow

1. Receive an image from Telegram.
2. Extract the file path and required metadata.
3. Send the raw image to Nano Banana for editing.
4. Collect feedback and loop until the image is approved.
5. Convert the final image into a usable URL.
6. Use Gemini v3 / Google AI to generate a short video.
7. Return the final result.

---

## Detailed project flow

### Telegram image input

- Start with a Telegram trigger node.
- Capture the incoming image file and its metadata.
- Use the file path to pass the image into the AI editing flow.

### Nano Banana editing and feedback loop

- Send the image to Nano Banana via its official API.
- Receive the edited image as a Base64 string.
- Convert the Base64 output into a usable file object.
- Present the edited image back to the user for feedback.
- Continue the loop if additional edits are requested.

### Converting images to URLs

- After finalizing the image, upload it to an external image-hosting API.
- The workflow uses a service like imagevb or similar third-party uploader.
- Provide your API key and POST the image data to receive a file URL.
- This URL is required by Gemini v3 for video generation.

---

## Gemini v3 video generation

- The project uses Google Gemini v3 for short video creation.
- The workflow supplies:
  - a reference image URL
  - a descriptive user prompt
  - video format details such as `9:16` portrait or landscape settings
- Gemini v3 returns a video generation payload, which may include a callback URL if processing takes time.

### Why Gemini v3

- Supports realistic, mobile-first video creation.
- Works well for UGC / ad-style short clips.
- Can be integrated through API calls from n8n.

---

## Agent-based prompt control

The workflow uses a dedicated AI agent that acts as a UGC video director.

- System prompt defines the agent as a `v3 fast UGC video generator`.
- The agent is instructed to create realistic eight-second video prompts.
- The agent combines the reference image description, user text prompt, and visual style guidance.
- Output is returned in strict JSON with fields like:
  - model
  - aspect ratio
  - enable fallback
  - prompt
  - image URL

### Why use an agent

- An agent helps convert vague creative requests into structured video instructions.
- It makes the video generation workflow more reliable.
- It ensures the output is suitable for automation and downstream API consumption.

---

## API integration best practices

### Use official APIs

- The demo emphasizes using the official Nano Banana API for image editing.
- It also uses official Google / Gemini API endpoints for video generation.
- Official APIs help avoid compatibility issues and vendor restrictions.

### Read the documentation

- Always inspect the provider docs before wiring the workflow.
- Understand required fields, supported image formats, and callback behavior.
- Use curl or HTTP request import features to translate docs into n8n nodes.

### Handle large execution data

- Image Base64 payloads can be large.
- Pin or manage data carefully to avoid n8n execution size limitations.
- Convert binary image data to URLs where possible instead of storing huge blobs.

---

## Practical implementation notes

- Convert Nano Banana edited images to Base64 strings and then to files.
- Use a dedicated HTTP request node to upload images and receive a hosted URL.
- Protect API keys and use separate credentials for each service.
- If video generation is asynchronous, use webhook callback URLs for completion.
